## 1. Что подтверждено реальным кодом прямо сейчас

- FastAPI-приложение (`api.py`, 1811 строк), 54 роута, HTTP Basic Auth на
  всём приложении, без CORS middleware.
- SQLite-схема из 17 таблиц, единая точка создания (`database.py::init_db`),
  additive-миграции строго соблюдаются (включая один управляемый rebuild
  таблицы `vehicle_gps_pings` для снятия `NOT NULL`).
- Геозона-детекция и авто-инциденты **реально работают в коде**, но только
  для двух правил: `SECTOR_EXIT` (выход за границу по Telegram Live
  Location) и `EMERGENCY` (кнопка тревоги). Дедупликация — по открытому
  инциденту с тем же `rule_code`+`entity_id`.
- AI-рекомендации по инцидентам (`services/ai_resolution.py`) генерируются
  синхронно при детекции, `max_tokens=2048`, строгий anti-hallucination
  промпт, JSON-контракт с опциями и оценкой финансового ущерба.
- AI Inspector на дашборде — **client-side JS-калькулятор**, не вызывает
  LLM в реальном времени. `loadIncidentsEquipment()` показывает уже готовые
  AI-рекомендации инцидентов. `startTypewriter()` — имитация печати
  (`setInterval` по готовой строке), не настоящий стриминг. Backend
  streaming-эндпоинта не существует.
- Claude Vision заменил Tesseract для OCR планов границ
  (`services/robez_ocr_vision.py`), без кэширования по хэшу файла.
- Copernicus/Sentinel Hub интегрирован напрямую в `api.py` (не в
  `services/`), снимки/NDVI считаются on-the-fly, не персистятся.
- **В репозитории нет `requirements.txt`/аналога** — зависимости нигде не
  зафиксированы файлом.

## 2. Найденная в этой сессии несостыковка (не выдумка, видно в коде)

`api.py::get_sectors()` (эндпоинт `/api/sectors`, список) отдаёт
`exposure_label` (строку), но **не отдаёт** `exposure_low`/`exposure_high`
числом — эти поля добавляются только в `/api/sectors/{name}` (детали
одного сектора). При этом `loadInspector()` во фронтенде суммирует именно
`sector.exposure_low`/`exposure_high` по массиву из `/api/sectors` для KPI
"⚠ Общий финансовый риск" на странице AI Inspector — то есть эта конкретная
KPI-карточка, по всей видимости, **всегда показывает €0**, независимо от
реальных рисков. Это не путать с финансовым риском на Overview
(`/api/summary`), который считается по-другому (сумма AI-оценок
инцидентов) и работает корректно. Стоит решить с пользователем, чинить ли
это до презентации или сознательно оставить как есть (раз Overview уже
показывает верную цифру).
